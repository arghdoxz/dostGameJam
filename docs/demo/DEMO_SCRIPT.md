# Demo Script

Video: `docs/demo/scratch-notes-development-demo.mp4` (3:05, 1600x900, 30 fps, H.264). It is a screen capture of the real game driven by `docs/demo/demo_commands.txt` (see [DEMO_NOTES.md](DEMO_NOTES.md)). The captions are drawn by the recording driver at the bottom of the screen. Art is placeholder throughout, and the caption on the first screen says so.
